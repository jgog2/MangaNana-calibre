Reading manga shouldn't turn into a damn IT project.

Application packages, runtime resources, tests and contributor tools live here. See the [project README](../README.md).

Build from the repository root with `python source/tools/build_plugin.py`, or run `python tools/build_plugin.py` from this directory. Developer guides: [Building](BUILDING.md), [Contributing](CONTRIBUTING.md), [Provider development](PROVIDER_DEVELOPMENT.md).
